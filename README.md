# Wildbound — Realms of Discovery

A mobile-first 3D creature-collecting adventure prototype built for iPhone Safari.

## Play
https://kj7342.github.io/Wildbound/ (once Pages deployment is enabled and the first workflow completes).

## Current prototype
- Stylized 3D meadow, village, lake, stream, trees, rocks and flowers
- Third-person elevated follow camera
- Touch joystick, jump and interact controls
- Keyboard controls for desktop testing (WASD / arrows, Space, E)
- Companion creature following the player
- Wild creatures roaming the meadow
- Local save position

## Technology
Three.js via CDN, deployed as a static site with GitHub Pages.

This is an early playable foundation, not the complete RPG. Creature capture, battles, quests, inventory, expanded regions, audio, and production-quality character/creature models are planned next.
